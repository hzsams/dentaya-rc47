# Real model experiment scope

These are controlled Windows experiments on the exact sources recorded in each source-info/report. They are not inference results for the final RC62 tag. Rejected model/policy candidates are retained deliberately: successful transport/schema checks do not mean a correct answer. Raw outputs contain only synthetic prompts, memory and CAD fixtures. No actual CAD command was executed. No model weights are included.

The original Qwen3 and Qwen3-Instruct-2507 candidates were rejected for identity/negation/memory failures and inadequate CAD evidence/save-result handling. Direct control inference separated basic model language limitations from AYA transport/template behavior. Final model acceptance must be recorded separately, with raw output and human semantic review.
